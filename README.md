# REELS_MODOBIT

Repositorio editorial y de producción de **Modo Bit**.

> **Tecnología que sí te sirve.**  
> **Entiende · Prueba · Decide**

## Objetivo

Crear contenido corto, claro y útil para Facebook Reels, Instagram Reels, TikTok y YouTube Shorts, con enfoque en tecnología aplicada a la vida real.

## Pilares de contenido

- 🤖 **Modo IA** — inteligencia artificial, automatización y herramientas.
- 💻 **Modo PC** — Windows, hardware, software y optimización.
- 📱 **Modo Móvil** — apps, smartphones, trucos y comparativas.
- 🎮 **Modo Gaming** — juegos, consolas, accesorios y recomendaciones.
- 🔐 **Modo Seguro** — seguridad digital, privacidad y prevención.
- 🧰 **Modo Herramientas** — recursos, tutoriales y soluciones prácticas.

## Criterio editorial

Cada publicación debe cumplir al menos una de estas funciones:

1. **Explicar** algo complejo de forma simple.
2. **Probar** una herramienta, producto o promesa.
3. **Comparar** opciones para ayudar a decidir.
4. **Resolver** un problema tecnológico real.
5. **Alertar** sobre riesgos, malas prácticas o compras innecesarias.

No publicamos noticias solo por publicarlas. La pregunta siempre es: **¿qué cambia para la persona que lo está viendo?**

## Formato maestro de Reel

- Resolución: **1080 × 1920**
- Aspecto: **9:16**
- FPS: **30**
- Duración objetivo: **28–40 s**
- Gancho: primeros **0–3 s**
- Subtítulos: siempre
- CTA: uno, claro y medible
- Identidad: azul marino/negro + blanco + amarillo
