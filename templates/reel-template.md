# Plantilla maestra de Reel — Modo Bit

## 1. Hook (0–3 s)

- Problema, contradicción o pregunta directa.
- Debe entenderse incluso sin audio.
- Texto grande: máximo 5–7 palabras.

## 2. Contexto (3–8 s)

- Explicar por qué debería importarle al espectador.
- Evitar introducciones personales largas.

## 3. Valor / prueba (8–22 s)

- Mostrar evidencia, ejemplo, comparación o resultado.
- Cambiar encuadre o estímulo visual cada pocos segundos cuando tenga sentido.

## 4. Conclusión (22–30 s)

- Responder o introducir el punto decisivo.
- No terminar con una conclusión vaga.

## 5. CTA (últimos 3–5 s)

Elegir solo uno:

- Seguir para la segunda parte.
- Comentar una palabra/opinión.
- Guardar el Reel.
- Compartir con alguien.

## Identidad Modo Bit

- Azul marino / negro.
- Blanco para texto principal.
- Amarillo para palabras clave.
- Logo discreto.
- Voz directa, cercana y práctica.
- Nada de relleno.
