# Shotlist — Reel 001

## Formato

- 1080 × 1920
- 9:16 vertical
- 30 fps
- 28–35 segundos

## Tomas

### Toma 1 — Inicio de ChatGPT
**Tiempo:** 0–3 s  
**Visual:** interfaz limpia de ChatGPT, encuadre vertical mediante Pan/Crop.  
**Movimiento:** ligero zoom hacia el centro.  
**Texto:** `¿PAGAR CHATGPT? 💸`

### Toma 2 — Escribiendo el prompt
**Tiempo:** 3–8 s  
**Visual:** zoom al cuadro de entrada mientras se escribe una consulta.  
**Movimiento:** desplazamiento suave hacia el prompt.

Prompt sugerido:
> Dame 5 ideas para promocionar una cafetería pequeña en Facebook sin gastar dinero.

### Toma 3 — Respuesta
**Tiempo:** 8–16 s  
**Visual:** desplazamiento/zoom hacia la respuesta.  
**Texto:** `GRATIS ≠ INÚTIL`

### Toma 4 — Herramientas / archivos
**Tiempo:** 16–23 s  
**Visual:** mostrar brevemente opciones de archivos y herramientas disponibles.  
**Texto:** `¿LO USAS PARA TRABAJAR?`

### Toma 5 — Cambio de ritmo
**Tiempo:** 23–29 s  
**Visual:** volver a una vista limpia de ChatGPT o usar tres tarjetas/logos.  
**Texto:** `¿ES CHATGPT LA MEJOR IA?`

### Toma 6 — Cierre
**Tiempo:** 29–35 s  
**Visual:** fondo Modo Bit.  
**Texto principal:** `CHATGPT ⚔ GEMINI ⚔ DEEPSEEK`  
**CTA:** `SÍGUENOS PARA VER CUÁL GANA ⚡`

## Reglas visuales

- No mostrar información privada en la barra lateral.
- Evitar capturas demasiado abiertas: el contenido debe leerse en móvil.
- Cada zoom debe dirigir la atención a algo concreto.
- Evitar transiciones llamativas sin función.
- Usar blanco + amarillo para mensajes clave.
- Mantener el logo de Modo Bit pequeño y discreto.
